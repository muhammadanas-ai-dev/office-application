## Needs attention for a commercial release

These licences have copyleft terms. Review them with a
lawyer before a commercial release:

- **ONLYOFFICE Docs Community** — AGPLv3 (the editor/converter engine; see above).
- **Ghostscript** — AGPLv3 (PDF compression; see above).
- **poppler-utils (pdftoppm)** — GPLv2+ (PDF rendering for OCR / image export; see above).

## How this was generated

`node scripts/license-audit.mjs` — it reads each installed
package's own `package.json` in `node_modules`, so the
licence listed is the one the package itself declares.
The system tools and engines are listed by hand (they are
not npm packages).
